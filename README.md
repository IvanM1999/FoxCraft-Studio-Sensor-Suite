# FoxCraft-Studio-Sensor-Suite
Esta aplicação segue exatamente a mesma arquitetura de alta qualidade do CatCalc Pro, mas com uma identidade visual temática de raposa (tons quentes de laranja, terracota e areia) e ferramentas voltadas para eletrónica, baterias de lítio, divisores de tensão e conversores ADC para microcontroladores (ESP32/Arduino).
